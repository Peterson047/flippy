# **App Name**: Flippy

## Core Features:

- News Display: Display news items from the RSS feed in a full-screen format.
- Swipe Navigation: Enable vertical swiping to transition between news items, mimicking short video apps.
- Background Image: Use the main image from each news item as a full-screen background.
- Fade Effect: Apply a dark fade effect from bottom to top on the background image to improve text readability.
- Title Display: Display the news title prominently at the bottom of the screen.
- AI Summary: Generate a concise, 5-line summary of each news item using AI as a tool.
- Link to Original Article: Include a 'Ler na íntegra' (Read More) button that opens the original news article in a new tab.
- Feed Management: Implement a menu to search for news topics and add more RSS feeds, saving all data in local storage.

## Style Guidelines:

- Primary color: Use a vibrant blue (#29ABE2) to reflect trust and news delivery.
- Background color: Very dark grey (#121212) to emphasize content and readability.
- Accent color: Bright white (#FFFFFF) for text and key UI elements for contrast.
- Font pairing: 'Poppins' (sans-serif) for titles and summaries, and 'Inter' (sans-serif) for body text and button labels.
- The image fills the screen. At the bottom there is a translucent dark box containing the title, the AI summary, and a call to action button to read the full story. The button floats right.
- Smooth vertical transitions with a subtle fade effect during swipes, similar to TikTok.
